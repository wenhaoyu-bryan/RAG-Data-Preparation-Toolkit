# Roadmap

## v3.0 (Current)

- Modular architecture (rag_data_toolkit package)
- Multi-format export: CSV, JSONL, Dify
- Eval sample generation
- Streamlit UI with format selector

## v3.1 (Next)

- [ ] PDF input support
- [ ] HTML input support
- [ ] Markdown input support
- [ ] LangChain Document loader output format
- [ ] LlamaIndex Document loader output format
- [ ] Chunk size / overlap configuration
- [ ] Deduplication across chunks

## v4.0 (Future)

- [ ] OCR for scanned documents
- [ ] Multi-language support (English SOPs)
- [ ] REST API endpoint
- [ ] Docker deployment
- [ ] Integration with Dify / LangChain / LlamaIndex pipelines
- [ ] Automated RAG quality metrics (retrieval precision, answer accuracy)
- [ ] Document diff (re-process only changed sections)
